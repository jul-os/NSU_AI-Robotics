# telegram-bot
Проект по декларативному программированию

Задание:
Telegram-bot c функцией напоминальника. Типа боту посылаем команду:
remember 2019-02-07 20:30 “Сделать что-то великое”

И он пришлет напоминание. Желательно без использования готовых библиотек по созданию телеграм-ботов. Другие сетевые библиотеки можно использовать.

Функционал:
    Пользователь может:
        - поставить напоминание (день, время, нужен ли повтор, текст)
        - редактировать напоминание
        - удалить напоминание
        - настроить время вечернего уведомления
    Бот делает:
        - бот отправляет напоминания в нужное время
        - вечером бот предлагает пользователю поставить в него напоминания на завтра
        

Дополнительно, если останется время:
    Пользователь может:
        - записать список дел на день
        - отмечать выполнение дел
    Бот делает:
        - утром бот присылает список дел пользователя на этот день
